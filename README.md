## 🌐 Project Overview
Hospital Management System (HMS) is a full-stack web application designed to digitize and automate hospital operations. It manages patient registration, appointments, queue management, doctor consultation, diagnosis recording, prescription management, and user roles.

## ⚙️ System Architecture
Patient → Receptionist → Appointment → Queue → Doctor → Diagnosis → Prescription → Completed

## 🧠 Core Roles
| Role | Responsibilities |
|------|----------------|
| Admin | Manage users and system |
| Receptionist | Patient registration and appointments |
| Doctor | Consultation and treatment |

## 🚀 Features
- Secure Authentication System
- Role-Based Access Control (RBAC)
- Patient Management System
- Appointment Scheduling
- Queue Management
- Medical History Tracking
- Doctor Consultation Module
- Prescription Management
- REST API (PHP)
- MySQL Database Integration

## 🏗️ System Architecture
Frontend (React.js) → Backend (Core PHP REST API) → Database (MySQL)

## 🧰 Technology Stack
Frontend: React.js  
Backend: Core PHP (REST API)  
Database: MySQL  
Server: Apache / XAMPP  

## 📁 Project Structure
HMS/
├── frontend/
├── backend/
├── database/

## 🔄 System Workflow
Patient Arrives → Receptionist Registers → Appointment Created → Queue → Doctor Consultation → Diagnosis → Prescription → Done

## 📌 Functional Modules
Authentication Module: Login, logout, session control  
User Management: Add, update, roles  
Patient Management: Register and search patients  
Appointment Module: Schedule and assign doctors  
Consultation Module: Diagnosis and prescription  

## 🖥️ System Pages
Admin: Dashboard, Manage Users  
Receptionist: Patient List, Register Patient, Appointments  
Doctor: Dashboard, Patient History, Consultation Page  

## 🔒 Non-Functional Requirements
- Response time < 3 seconds
- Secure authentication (bcrypt)
- Role-based access control
- Scalable architecture
- Data consistency

## 📈 Future Enhancements
- AI-based diagnosis
- Mobile app support
- Billing system
- Notifications (SMS/Email)
- Analytics dashboard
- Laboratory module

## 🎯 Project Goal
To replace manual hospital systems with a fast, scalable, and digital healthcare management platform.
